# Futuras Referencias Visuais

Esta pasta e reservada para propostas visuais ainda nao aprovadas.

Propostas aqui nao podem ser usadas como contrato de implementacao. Cada proposta deve registrar data, autor, objetivo, tela ou fluxo afetado e status.

Uma proposta so pode migrar para nova versao oficial depois de aprovacao do Product Owner. Referencias propostas nunca devem ser misturadas com referencias aprovadas.
