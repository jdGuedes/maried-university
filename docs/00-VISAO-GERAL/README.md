# Visão Geral

A MARIED UNIVERSITY é um SaaS modular para semijoias e folheados.

## Proposta

Resolver tarefas simples com ferramentas simples, acessíveis e integradas.

## Público-alvo

- iniciantes;
- pequenos fabricantes;
- revendedores;
- lojistas;
- pessoas que usam planilhas, papel ou calculadora.

## Regra central

Uma aplicação, um banco, um login e vários módulos contratáveis.
