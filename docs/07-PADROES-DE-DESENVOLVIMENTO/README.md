# Padrões de Desenvolvimento

- TypeScript strict.
- Regras de negócio fora de componentes React.
- Funções puras em motores.
- Testes unitários para fórmulas.
- Dinheiro com `numeric`/`decimal`.
- RLS obrigatória.
- `tenant_id` em tabelas operacionais.
- Segredos somente em variáveis de ambiente.
- Migrations versionadas.
