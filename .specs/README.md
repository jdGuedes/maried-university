# Especificacoes

Nenhuma funcionalidade relevante deve ser implementada sem uma SPEC aprovada.

Cada SPEC deve conter:

- objetivo;
- problema;
- escopo;
- fora do escopo;
- fluxos;
- regras;
- banco;
- permissoes;
- integracoes;
- testes;
- criterios de aceite;
- riscos;
- Definition of Done.
