# Integration Tests

Testes de integracao da SPEC-002 Entrega C cobrem contratos de fluxo de autenticacao, allow-list de redirect, bloqueio de open redirect e mensagens seguras.

Comando:

```bash
npm run web:test:integration
```

## SPEC-002 Entrega E

Inclui contratos de manifest, icones existentes e service worker: allow-list segura, Network Only para rotas sensiveis e atualizacao controlada.
